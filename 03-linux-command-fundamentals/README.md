#
Nearly every security tool is a command-line tool, and nearly every write-up assumes you can already move around a Linux filesystem without thinking about it. That assumption is where most people stall: not on the hacking, on the shell.

This lab covers the small set of commands that the other seventeen labs quietly depend on — moving between directories, reading files without opening an editor, understanding what a permission string means, finding a file when you only know part of its name, and seeing which processes are listening on which ports.
